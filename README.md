
# PROJECT NEXUS

A futuristic browser-based desktop environment.

## Features

- Desktop interface
- Start menu
- Application search
- Draggable application windows
- Minimise, maximise and close
- File Explorer demo
- Notes with automatic local saving
- Calculator
- Personalisation settings
- Accent colour selection
- Wallpaper selection
- Control Centre interface
- Keyboard shortcuts
- PWA support
- Basic offline caching

## Installation

1. Upload all project files to a GitHub repository.
2. Open repository Settings.
3. Select Pages.
4. Under Build and Deployment, select Deploy from a branch.
5. Select the main branch and root folder.
6. Save and wait for deployment.

## Keyboard Shortcuts

- Ctrl + K: Search
- Alt + Tab: Switch windows
- Escape: Close open menus

## Important Limitations

PROJECT NEXUS is a browser-based desktop simulation, not a replacement for Windows or Android.

The File Explorer uses demo folders rather than direct access to the device filesystem.

Control Centre switches are interface simulations. They do not change actual device Wi-Fi, Bluetooth, brightness or volume.

Websites open through browser navigation rather than native desktop windows.

Native Android apps cannot be launched as desktop windows by this web application.

Wireless display and remote desktop streaming are not included.
